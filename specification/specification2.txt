### Mission 2: 요청과 응답을 눈으로 확인하기

**목표**: 브라우저에서 localhost:8000에 접속했을 때, 서버가 받는 요청(Request)의 실제 형태를 터미널에 출력한다.

**달성 기준**:

- 브라우저에서 접속 시, 터미널에 HTTP 요청 원문이 출력된다.
- 요청의 구조(메서드, 경로, 헤더 등)를 눈으로 확인할 수 있다.

**확인해야 할 것**:

- HTTP 요청은 어떤 형태의 텍스트인가?
- GET 요청과 POST 요청의 차이는 무엇인가?
- 헤더(Header)에는 어떤 정보가 담겨 있는가?

**제출물**: 요청 출력 코드 + 터미널에 출력된 요청 원문 캡처(혹은 코드블럭)
