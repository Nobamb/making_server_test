### Mission 3: HTML을 조립하여 응답으로 전송하기

**목표**: 서버에서 HTML 문자열을 조립한 뒤, 브라우저에 응답으로 전송한다. 브라우저 콘솔에서 "응답을 받았습니다" 메시지를 확인한다.

**달성 기준**:

- 브라우저에 HTML 페이지가 렌더링된다.
- 브라우저 개발자 도구(F12) 콘솔에 "응답을 받았습니다" 메시지가 출력된다.
- 서버 터미널에 응답 전송 로그가 출력된다.

**확인해야 할 것**:

- HTTP 응답은 어떤 형태로 구성되는가?
- 상태 코드(200, 404 등)는 무엇을 의미하는가?
- Content-Type 헤더의 역할은 무엇인가?
- 브라우저는 응답을 받아서 어떻게 화면에 그리는가?

**제출물**: 응답 전송 코드 + 브라우저 렌더링 화면 캡처 + 콘솔 메시지 캡처(혹은 코드블럭)
